# 🌤️ Weather Telegram Bot

Телеграм-бот для отслеживания погоды с персональными рекомендациями одежды.

## 📋 Возможности

- ☀️ Автоматическая утренняя сводка погоды каждый будний день в 7:00
- 🌧️ Предупреждение о дожде в школьное время (утром и после школы)
- 👔 Рекомендации одежды на основе температуры и погоды
- 📸 Сохранение фотографий твоего гардероба для персональных рекомендаций
- 📅 Учет расписания школы по дням недели

## 🚀 Установка

### 1. Установи Python

Убедись что у тебя установлен Python 3.8 или новее:
```bash
python --version
```

### 2. Установи зависимости

Открой терминал в папке `weather_telegram_bot` и выполни:
```bash
pip install -r requirements.txt
```

### 3. Проверь настройки

Файл `config.py` уже содержит все твои настройки:
- Токен бота
- API ключ погоды
- Город: Zielona Gora
- Расписание школы

## ▶️ Запуск

```bash
python weather_bot.py
```

Бот запустится и будет работать. Не закрывай окно терминала пока бот работает.

## 📱 Как использовать

### Первый запуск
1. Найди своего бота в Telegram
2. Отправь команду `/start`
3. Бот начнет присылать утренние сводки каждый будний день в 7:00

### Команды бота

- `/start` - запустить бота и включить утренние уведомления
- `/weather` - текущая погода
- `/forecast` - прогноз на сегодня с учетом школьного расписания
- `/add_clothes` - добавить одежду в гардероб
- `/wardrobe` - посмотреть весь гардероб
- `/stop` - остановить утренние уведомления

### Добавление одежды

1. Отправь команду `/add_clothes`
2. Отправь фото одежды с подписью, например:
   - "Синяя куртка для холодной погоды"
   - "Летняя футболка"
   - "Зимняя шапка"
3. Бот сохранит фото и описание

## 📅 Расписание

Бот знает твое расписание:
- **Понедельник, Среда**: 8:00 - 14:35
- **Вторник, Четверг**: 8:00 - 15:25
- **Пятница**: 8:00 - 13:40

## 🌡️ Рекомендации одежды

Бот автоматически рекомендует одежду в зависимости от температуры:
- **Ниже 5°C**: теплая куртка, шапка, шарф, перчатки
- **5-15°C**: куртка, джинсы, свитер
- **15-20°C**: легкая куртка или толстовка
- **20-25°C**: футболка, легкие штаны
- **Выше 25°C**: футболка, шорты

Если ожидается дождь - бот добавит зонт или дождевик в рекомендации.

## 🔧 Настройка

Все настройки находятся в файле `config.py`:
- `MORNING_REPORT_TIME` - время утренней сводки
- `SCHEDULE` - расписание школы
- `CITY` - город для прогноза погоды
- `CLOTHING_RECOMMENDATIONS` - рекомендации одежды

## ⚠️ Важно

- Бот должен постоянно работать чтобы отправлять утренние сообщения
- Не делись токеном бота с другими
- API ключ OpenWeatherMap бесплатный, но имеет лимиты (60 запросов/минуту)

## 🐛 Проблемы

Если бот не работает:
1. Проверь что Python установлен: `python --version`
2. Проверь что все библиотеки установлены: `pip install -r requirements.txt`
3. Проверь что токен бота правильный
4. Проверь что API ключ активирован (может занять 10-15 минут после регистрации)

## 📝 Лог

Бот пишет логи в консоль. Если что-то не работает - смотри ошибки там.
